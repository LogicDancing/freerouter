# FreeRouter 安装与使用指南

## 环境要求

- Python 3.10 或以上
- 至少一个免费 API Key（全部无需信用卡）

---

## 第一步：获取免费 API Key

| 平台 | 注册地址 | 需要翻墙 | 备注 |
|------|----------|----------|------|
| NVIDIA Build | https://build.nvidia.com | ✅ 需要 | 模型最多，旗舰首选 |
| Groq | https://console.groq.com | ✅ 需要 | 速度最快，每天重置 |
| Cerebras | https://cloud.cerebras.ai | ✅ 需要 | 1M token/天最慷慨 |
| SambaNova | https://cloud.sambanova.ai | ✅ 需要 | 405B 全精度备选 |

> **注意**：四个平台目前均需要翻墙注册和使用。
> 国内访问建议使用稳定的代理工具，API 调用本身也需要代理。

### Groq 注册问题说明

Groq 注册时出现「不属于任何组织」错误，通常有两个原因：

1. **邮箱未验证** — 注册后检查邮箱，点击验证链接，再重新登录
2. **企业/学校邮箱限制** — 改用 Gmail / Outlook 个人邮箱注册
3. **地区限制** — 切换代理节点到美国或欧洲，清除浏览器 Cookie 后重试

---

## 第二步：安装 FreeRouter

```bash
# 方式一：pip 安装（推荐）
pip install freerouter

# 方式二：从源码安装
git clone https://github.com/yourname/freerouter
cd freerouter
pip install -e .
```

---

## 第三步：初始化配置

```bash
freerouter init
```

按提示输入各平台 API Key，或提前设置环境变量：

```bash
export NVIDIA_API_KEY=nvapi-xxxx
export GROQ_API_KEY=gsk_xxxx
export CEREBRAS_API_KEY=csk-xxxx
export SAMBANOVA_API_KEY=xxxx
```

---

## 第四步：配置 opencode

```bash
freerouter setup
```

这会自动把 opencode 的配置文件指向 FreeRouter 代理。
配置完成后 `~/.config/opencode/opencode.json` 变为：

```json
{
  "openai": {
    "baseURL": "http://localhost:8080/v1",
    "apiKey": "freerouter-local",
    "model": "auto"
  }
}
```

---

## 第五步：启动代理

```bash
freerouter start
```

终端会显示各平台实时延迟。此后 opencode 所有请求自动路由到最快的平台。

---

## 常用命令

```bash
freerouter probe          # 检查各平台当前延迟
freerouter probe --watch  # 持续监控（每 10s 刷新）
freerouter status         # 查看代理运行状态
freerouter start --no-dashboard  # 静默启动（不显示看板）
```

---

## 关于代理设置

FreeRouter 本身不内置代理，需要系统级代理生效。

**macOS / Linux：**
```bash
export https_proxy=http://127.0.0.1:7890
export http_proxy=http://127.0.0.1:7890
freerouter start
```

**Windows（PowerShell）：**
```powershell
$env:https_proxy = "http://127.0.0.1:7890"
freerouter start
```

将 `7890` 替换为你的代理端口。

---

## 故障排查

| 现象 | 原因 | 解决 |
|------|------|------|
| `probe` 全部超时 | 代理未生效 | 检查系统代理设置 |
| 429 Rate Limited | 配额用完 | 等待重置（Groq/Cerebras 每天重置） |
| opencode 仍用旧模型 | 配置未生效 | 重启 opencode 后重试 |
| `freerouter start` 报端口占用 | 8080 被占用 | `freerouter start --port 8081` |
